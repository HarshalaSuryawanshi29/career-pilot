# GitHub-style Profile Portfolio Theme

This template mirrors GitHub's profile aesthetic while avoiding any trademarked logos.

Files
- `index.html` — template with placeholders and semantic structure
- `style.css` — dark GitHub-like styling (colors: `#0D1117`, `#161B22`)
- `script.js` — minimal renderer: fills sidebar, renders markdown, projects and heatmap

Design
- Left sidebar with avatar, bio and social links
- Right content area with README-style about section, pinned projects grid, and contribution heatmap
- Contribution greens: range `#e6f4ea` → `#39d353` (visual scale uses `#216e39` for strongest)
- Typography: `-apple-system`, `Segoe UI`, system stack

Usage
Edit the `PORTFOLIO` object at the top of `script.js` with your data and open `index.html`.

Do NOT use GitHub's Octocat or other trademarked logos in this theme.
